# i18n EN — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crear 11 páginas en inglés bajo `/en/` con hreflang correcto, switcher ES|EN navegable y cero cambios visuales en las páginas españolas existentes.

**Architecture:** Directorio `src/en/` con archivos `.njk` independientes. Datos EN en `src/_data/locationsEn.json` (disponible globalmente). Layout `location-en.njk` reutiliza la misma estructura visual que `location.njk`. Frontmatter `langEs`/`langEn`/`currentLang` en todas las páginas alimenta hreflang y switcher.

**Tech Stack:** Eleventy 3.x · Nunjucks · HTML

**Rama:** `feature/arquitectura-multipagina`
