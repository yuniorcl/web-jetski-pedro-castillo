Crear versiones en inglés de las 11 páginas principales con URLs `/en/` independientes, hreflang correcto en todas las páginas, y switcher ES|EN que navega a URLs reales en lugar de usar JS client-side.

- **Reutilización de layouts** — `location-en.njk` es idéntico a `location.njk` pero usa datos EN.

## Cambios a archivos existentes

### `src/_includes/head.njk` — hreflang dinámico

Reemplazar las 2 líneas de hreflang actuales por 3 líneas dinámicas:

**Antes:**
```html
<link rel="alternate" hreflang="es" href="https://jetexperiencemallorca.com/">
<link rel="alternate" hreflang="x-default" href="https://jetexperiencemallorca.com/">
```

**Después:**
```njk
<link rel="alternate" hreflang="es" href="{{ langEs }}">
<link rel="alternate" hreflang="en" href="{{ langEn }}">
<link rel="alternate" hreflang="x-default" href="{{ langEs }}">
```

### `src/_includes/header.njk` — switcher como links

**Antes:**
```html
<button data-lang-btn="es" class="lang-btn active">ES</button>
<span class="lang-sep">|</span>
<button data-lang-btn="en" class="lang-btn">EN</button>
```

**Después:**
```njk
<a href="{{ langEs }}" class="lang-btn{% if currentLang == 'es' %} active{% endif %}">ES</a>
<span class="lang-sep">|</span>
<a href="{{ langEn }}" class="lang-btn{% if currentLang == 'en' %} active{% endif %}">EN</a>
```

Mismo diseño visual — solo cambia `<button>` por `<a>` y la clase `active` se aplica según `currentLang`.

### Frontmatter a añadir a TODAS las páginas ES existentes

Cada página `.njk` en español añade estos 3 campos:

```yaml
langEs: "https://jetexperiencemallorca.com/[slug-es]/"
langEn: "https://jetexperiencemallorca.com/en/[slug-en]/"
currentLang: es
```

## Limitaciones conocidas (aceptadas en v1)

- Los links "Zonas de servicio" del footer siempre apuntan a URLs españolas. En páginas EN, un clic en "Cala Millor" del footer lleva a `/jet-ski-cala-millor/` (ES). No es ideal para UX pero es aceptable en v1 — Google lo resolverá vía hreflang.
- El botón flotante WhatsApp (en `footer.njk`) usa el mensaje en español incluso en páginas EN. El mensaje de WhatsApp hardcodeado en `location-en.njk` y las páginas de servicio EN sí es en inglés.
- El `sobre-nosotros` link del footer debe actualizarse en `footer.njk` para mostrar "About Us" en páginas EN: `{% if currentLang == 'en' %}<a href="/en/about-us/">About Us</a>{% else %}<a href="/sobre-nosotros/">Sobre Nosotros</a>{% endif %}`
