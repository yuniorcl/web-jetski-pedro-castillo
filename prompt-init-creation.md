Actúa como un programador profesional especializado en webs estáticas modernas, responsive, optimizadas para SEO local y fáciles de mantener.

Necesito crear una web estática para una empresa de alquiler y excursiones en jet ski / motos de agua, inspirada en webs como saroquetajetski.com y otras webs actuales de renta de jet ski en zonas turísticas.

OBJETIVO PRINCIPAL
Crear una web estática contemporánea, rápida, visual, clara y orientada a conseguir reservas por WhatsApp, llamada o formulario. La web debe poder publicarse fácilmente en un hosting tradicional y debe estar preparada para posicionar en Google.

TIPO DE WEB
Landing page estática profesional para alquiler de jet ski.

TECNOLOGÍAS
Usar:
- HTML5 semántico
- CSS3 moderno
- JavaScript vanilla solo si es necesario
- Estructura de archivos limpia
- Sin frameworks pesados
- Código preparado para hosting estático
- Responsive para que se pueda visualizar desde dispositivos moviles. Aqui si quieres puedes utilizar un bootstrap o alguno similar para ese tema de responsive o alguno más moderno y con mejor precencia
- Para las traducciones arrancamos con el idioma ES y EN, pero la web debe tener la opción de cambiar el idioma.

ESTRUCTURA DE ARCHIVOS
Crear una estructura similar a:

/index.html
/assets/
/assets/img/
/assets/i18n/
/assets/icons/
/assets/css/styles.css
/assets/js/main.js

-- Esto es una propuesta el diseño final lo defines tu.

REQUISITOS DE DISEÑO
Crear un estilo sencillo, limpio y contemporáneo:
- Diseño moderno, turístico y veraniego
- Colores relacionados con mar, aventura, confianza y energía
- Tipografía legible y actual
- Mucho espacio en blanco
- Botones claros de llamada a la acción
- Imágenes grandes y atractivas
- Diseño mobile-first
- Totalmente responsive para móvil, tablet y escritorio
- Animaciones suaves, sin sobrecargar la web.
- incluir proteción ante scraping y ataques de robot o mini hacker.
- Empesamos con idioma(ES(default),EN) pero la web debe ser multiidioma. por tanto los textos de los literales deben estar en un fichero de idioma.  En las IMG vamos a intentar no incluir idiomas. así si hay cambios no afectamos al idiama y si ponemos textos en las IMG serán en INGLES que es universal.

SECCIONES DE LA WEB

1. Header
- Logo o nombre de marca
- Menú de navegación
- Botón destacado “Reservar ahora”
- Menú responsive en móvil

2. Hero principal
- Imagen o fondo visual potente de jet ski en el mar
- Título principal SEO:
  “Alquiler de Jet Ski en [Ciudad/Zona]”
- Subtítulo orientado a conversión:
  “Vive una experiencia única en el mar con nuestras motos de agua”
- Botones:
  “Reservar por WhatsApp”
  “Ver precios”
- Elementos de confianza:
  “Sin licencia”
  “Instructor incluido”
  “Reserva rápida”
  “Experiencia segura”

3. Sección de experiencias
Crear tarjetas para diferentes opciones:
- Ruta de 30 minutos
- Ruta de 1 hora
- Ruta sunset
- Excursión privada
Cada tarjeta debe incluir:
- Imagen
- Nombre de la experiencia
- Duración
- Precio desde
- Breve descripción
- Botón “Reservar”

4. Sección “Por qué elegirnos”
Incluir ventajas:
- Motos de agua modernas
- Monitores profesionales
- Seguridad incluida
- Ideal para parejas, amigos y familias
- Reserva fácil por WhatsApp
- Ubicación privilegiada

5. Sección de precios
Mostrar precios de forma clara:
- 30 minutos
- 60 minutos
- 90 minutos
- Pack especial
Incluir nota:
“Precios orientativos. Consulta disponibilidad y condiciones.”

6. Sección de galería
Crear una galería visual con imágenes de:
- Jet ski
- Mar
- Clientes disfrutando
- Costa o calas
La galería debe ser responsive.

7. Sección de proceso de reserva
Explicar en 3 o 4 pasos:
1. Elige tu experiencia
2. Contacta por WhatsApp
3. Confirma día y hora
4. Disfruta de tu ruta en jet ski

8. Sección de seguridad
Explicar:
- Chaleco salvavidas incluido
- Briefing inicial
- Monitor o guía profesional
- Normas básicas antes de salir
- Actividad apta para principiantes

9. Sección FAQ
Crear preguntas frecuentes:
- ¿Necesito licencia?
- ¿Pueden ir dos personas en una moto?
- ¿Qué debo llevar?
- ¿Desde qué edad se puede participar?
- ¿Qué pasa si hace mal tiempo?
- ¿Cómo puedo reservar?

10. Sección ubicación
Incluir:
- Nombre de la zona
- Dirección aproximada
- Botón “Cómo llegar”
- Espacio preparado para insertar Google Maps

11. Sección final CTA
Crear una llamada a la acción fuerte:
“Reserva tu experiencia en jet ski hoy”
Botones:
- WhatsApp
- Llamar ahora
- Ver disponibilidad

12. Footer
Incluir:
- Nombre de empresa
- Teléfono
- WhatsApp
- Email
- Ubicación
- Enlaces rápidos
- Aviso legal
- Política de privacidad
- Copyright

SEO
La web debe estar optimizada para buscadores:
- Usar HTML semántico
- Un solo H1
- H2 bien estructurados
- Meta title optimizado
- Meta description atractiva
- URLs internas con anclas
- Textos orientados a búsquedas locales:
  “alquiler jet ski en [Ciudad]”
  “motos de agua en [Ciudad]”
  “excursiones jet ski [Zona]”
  “renta de jet ski cerca de mí”
- Añadir datos estructurados Schema.org para LocalBusiness o TouristAttraction
- Optimizar imágenes con atributos alt descriptivos
- Carga rápida
- CSS limpio
- JavaScript mínimo
- Preparar Open Graph para compartir en redes sociales

ACCESIBILIDAD
Cumplir buenas prácticas:
- Contraste correcto
- Botones accesibles
- Textos alternativos en imágenes
- Navegación por teclado
- Etiquetas correctas en formularios
- Tamaños de fuente legibles

MANTENIBILIDAD Y SOLID
Aunque sea una web estática, aplicar principios de código limpio y SOLID adaptados al frontend:
- Separar estructura HTML, estilos CSS y comportamiento JavaScript
- Evitar código duplicado
- Crear clases CSS reutilizables
- Usar variables CSS para colores, tamaños y espaciados
- JavaScript dividido en funciones pequeñas y claras
- Cada función debe tener una sola responsabilidad
- No mezclar lógica con presentación
- Código comentado solo donde sea útil
- Nombres de clases claros y consistentes
- Arquitectura sencilla para que otro desarrollador pueda mantenerla fácilmente

RENDIMIENTO
Optimizar para:
- Carga rápida
- Imágenes comprimidas
- Lazy loading en imágenes
- Evitar librerías innecesarias
- Buen rendimiento en móvil
- Buen resultado en Lighthouse

FORMULARIO
Crear un formulario simple de contacto/reserva con:
- Nombre
- Teléfono
- Fecha deseada
- Tipo de experiencia
- Mensaje
El formulario puede ser estático, preparado para conectar después con Formspree, Netlify Forms o backend externo.

WHATSAPP
Añadir botones de WhatsApp con mensaje predefinido:
“Hola, quiero reservar una experiencia de jet ski. ¿Me podéis informar de disponibilidad?”

TONO DE TEXTO
Usar textos comerciales, claros y naturales:
- Profesional
- Cercano
- Turístico
- Orientado a reservas
- Sin exageraciones excesivas

ENTREGABLE FINAL
Generar:
1. Código completo de index.html
2. Código completo de styles.css
3. Código completo de main.js si es necesario
4. Explicación breve de la estructura
5. Instrucciones para publicar en hosting
6. Recomendaciones SEO finales

IMPORTANTE
No crear una copia exacta de ninguna web existente. La web debe estar inspirada en el sector y en patrones habituales de webs modernas de alquiler de jet ski, pero con diseño propio, limpio y profesional.
